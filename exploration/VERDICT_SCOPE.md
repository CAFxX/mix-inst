# Verdict Scope Ledger — RV64 `mix` search

**Purpose:** every negative verdict ("X doesn't work") is scoped to the exact
configurations tested. A kill in one construction is not evidence against the
primitive in another. This ledger is the authority on what was actually
tested; round-table "findings" sections may phrase claims more broadly than
the evidence supports — when they do, this file wins.

**Reading a row:** `Tested` = the full construction(s) the verdict rests on.
`Claim` = the most we may assert. `Re-test trigger` = the new context that
would reopen the question. `Priority` = value of re-testing given the current
frontier (notr family, 37.4–37.9u).
