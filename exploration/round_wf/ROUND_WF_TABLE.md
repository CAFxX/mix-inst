# round_wf — wire-friendly P-box design for the r22c SPN family

**Directive:** Carlo 2026-10-04. **Goal:** permutations maximizing diffusion AND
minimizing global wire length — co-optimizing the cryptographic and
physical-design axes. The S0 unit-delay flow prices wiring at zero, so this
cost is invisible until S5 P&R; this track banks the win analytically now.

**Baseline (parent-measured 2026-10-04):** current r22c P-box P(i)=(5i+27)%64:
Σ|P(i)−i| = **1450 bit-pitches** (avg 22.66/bit, max stretch 57/64), no fixed
points, maximal per-S-box spreading (each lane's 4 output bits land in 4
distinct lanes — verified). Single 64-cycle (O34).

## Formulation (Phase B)

Constrained assignment on n=64, linear 64-bit datapath layout model:

- minimize **W** = Σ|P(i) − i| (wirelength proxy, bit-pitches)
- maximize **S** = Σ|⌊P(i)/4⌋ − ⌊i/4⌋| (spreading, lane units)
- s.t. (1) P is a single 64-cycle [O34 validity], (2) no fixed points,
  (3) **D_min = 4**: each source lane's 4 bits land in 4 DISTINCT target lanes
  (the diffusion property the current P-box has — preserved, not relaxed).

**Solver** (`solver/wf_sa.py`): simulated annealing on the *tour representation*
c[0..63] with P(c[k]) = c[(k+1) mod 64]. Every single 64-cycle has such a
representation; every tour yields one — so (1)+(2) hold **by construction**
(tour entries are distinct ⇒ P(i)≠i always). Swap moves preserve both.
Constraint (3) enforced by exact rejection (incremental delta evaluation,
O(1)/move — verified bit-exact against brute force on 10k random swaps).
Multi-λ sweep (λ ∈ {0,1,2,4,8,16,32} on S) × Dreq ∈ {4,3,2} × 3 seeds maps the
(W,S) Pareto frontier; Dreq ∈ {2,3} is diagnostic (cost of the maximal-spreading
requirement).

**Reference points** (same metrics): PRESENT pLayer (P(i)=16i%63, P(63)=63 —
has a fixed point, invalid for us), GIFT PermBits (P64(0)=0 — fixed point,
invalid), r22c baseline (valid).

## Methodology notes

- S0–S4 **cannot** see wirelength (synthesis counts gates; wiring is free).
  Selection among P-boxes uses the analytical proxy W; diffusion uses the real
  battery (S2/Q1). **Never present proxy wirelength as measured silicon** —
  the wirelength win is banked for S5 P&R confirmation.
- Bijectivity hard gate: single-cycle ⇒ bijective; verified per candidate
  (generator asserts; S2 xcheck cross-validates).
- Validation (Phase C): knee of frontier + wirelength champion → O34-style
  single-cycle check (by construction, verify) → S2 screen in r22c 4r context
  (N=2²², 115 deltas — the real diffusion gate) → full battery S0→S4 + Q1 for
  best 1–2. Candidate dirs: `validation/candidates/wf_pbox_<tag>_nw/`
  (impl.c + model.py + meta.json + rtl.v, generated by `gen_variant.py`).
- Coordination with round 23: that track's P-box sweep covers the O37 validated
  set (75 P-boxes); this track covers the SA-optimized family. Distinct
  `wf_pbox_*` names; no duplicated validation runs.
- Polite concurrency: ≤2 heavy pipelines system-wide; back off at ≥2 foreign
  heavies (count by binary). The SA grid is pure-Python, niced (nice -n 15).
- Never delete candidate dirs or round logs. Do NOT edit PARETO.md /
  VERDICT_SCOPE.md — flag results to parent with evidence paths.

## 2D placement-aware phase (2026-10-04 — track REOPENED with corrected objective)

**Parent directive (Carlo 2026-10-04):** the 1D phase's negative verdict stood
on a conflated metric. Correction:
- *Index-space locality* (short hops in bit-index) is what S2 kills. F1/F2/F3
  died from confined differential trails. The cipher has no geometry; 2D
  placement cannot rescue an index-local P-box. The dead region stays dead.
- *Physical locality* (wirelength after 2D placement) is what the placer sees.
  The 1450 baseline was measured under pessimistic LINEAR placement.
- **Corrected objective:** among DIFFUSION-VALIDATED (S2-clean) P-boxes,
  minimize 2D-placeable wirelength. Diffusion (index space, S2) and
  placeability (2D embedding) are separate metrics, not one conflated proxy.

**Machinery** (`place2d/`):
- Lane-communication graph: 16 S-box-lane nodes, 64 directed bit-wire edges,
  weights = wire count between lane pairs.
- 2D placement heuristic: SA over 4×4 grid lane assignments, Manhattan
  objective = Σ w[a][b]·(4·|dx| + V·|dy|), V=4 (square lane slots), in
  bit-pitches. Incremental O(deg) delta, verified bit-exact vs full recompute.
  8k iters × 2 seeds converges on baseline (424, confirmed vs 40k × 4).
- Candidate pool (diffusion-first): 384 O37-style affine validated P-boxes
  (P(i)=(a·i+b)%64, a odd, O34 criteria: single 64-cycle, no fixed points,
  Dmin=4 both directions; S range 302–378) + high-S SA tours (Dreq=4, S≥320)
  + baseline. Old W-minimizing SA optima are obsolete as candidates.

### Mechanistic insight: why random beats affine (2026-10-04)

Both baseline and S374 have 64 unit-weight edges (Dmin=4 → 4 distinct targets
per lane). The difference is purely structural. In the optimal 2D embedding:
- Baseline: edge-dist {0:4, 1:12, 2:15, 3:20, 4:9, 5:4} — peak at dist 3.
- S374:     edge-dist {0:8, 1:16, 2:14, 3:13, 4:8, 5:5} — more local edges.

S374's lane graph has more 2D cluster structure AND higher index spreading
(S=374>362). The 2D placement is free; index-space distance need not correlate
with graph adjacency. Affine maps (linear) preserve a locality correlation
that random tours break — which is why random P-boxes can win on both axes.
