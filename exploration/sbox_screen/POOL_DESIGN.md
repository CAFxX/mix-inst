## 2. The new pool: 8-bit S-boxes

### 2.1 Why 8-bit (per-axis justification vs the mix properties)

The mix needs strong nonlinearity per stage (quality gates S1–S4, Q1) at
few stages (cost bar: strictly < 18.6u, the t6_b59_47 Frontier S point).

- **4-bit is cost-closed for the frontier** (track-3 verdict, 2026-10-11):
  all 7 swept boxes > 3.3u/stage, and ≥4 stages are needed for quality
  (b48-class 3-stage wall: muxS3/q4bS3 0/6 KEEP, min z in the thousands).
  4 rounds × >3.3u + chassis overhead (r25 measured 26–30u) cannot reach
  18.6u. The 4-bit *box* axis is therefore not re-screened (principled
  cut — see §2.3).
- **8-bit changes the stage economics:** one 8-bit stage delivers twice
  the confusion width per nonlinear stage. A 2-round 8-bit SPN has the
  nonlinear depth of ~4 4-bit rounds in 2 stages. The cost thesis is
  falsifiable by this screen: **iff** an 8-bit box synthesizes < ~8u,
  2 rounds fit under 18.6u (2×8 + ~2.5u linear/whitening).
  Measured: AES_SBOX = 10.7u via the case emitter (pinned flow, yosys
  0.69). The thesis needs a box ≥25% cheaper than AES — the screen tests
  exactly this; a negative result COST-CLOSES the 8-bit SPN line
  (pre-registered, §6).
- **No blind swaps:** every pool entry is a complete, verified 8-bit
  permutation with measured (DU, NL, degree); the chassis (§5) is
  specified, not assumed.

### 2.3 Principled cut: no 4-bit in this pool

Per the search-breadth standing order, each cut needs its own defensible
reason:
1. **Coverage is complete** — 16/16 LE classes, 281 low-latency,
   all literature boxes, 28 mined, 12,288 variants (§1). Re-screening
   4-bit would re-run a closed pool, not widen.
2. **Cost-terminal** — track-3 (2026-10-11): 4-bit replacement
   > 3.3u/stage with ≥4 stages needed → cannot beat 18.6u. No 4-bit box,
   however cheap within its class (observed range 3.0–3.4u), changes this.

## 3. Screen machinery (what runs on GHA)

Three stages per box, via the extended tenant driver
(`driver/screen.py --pool-file pools/sbox8_pool.txt`):

- (a) **validate** (`flow/validate_sbox8.py`, numpy): bijective, DU,
  NL, per-coordinate ANF degree, full dependency, fixed points, cycle
  structure, differential branch number, boomerang uniformity.
  **Hard gates:** bijective ∧ DU ≤ 8 ∧ NL ≥ 96. (Degree/full-dependency
  recorded, not exclusionary.)
- (b) **unit-delay screen** (pinned flow: yosys 0.69, `abc -genlib
  mini.genlib`, dual-analyzer XCHECK): 8-lane 64-bit form, **case-statement
  emitter** (`gen_sbox.write_sbox64_8`). Rationale: ABC chokes on flat
  8-var ANF (AES: 101u) but optimizes the case form well (AES: 10.7u,
  4033 cells). Numbers are comparable *within* the 8-bit pool; a
  hand-optimized (composite-field) circuit can only improve them.
- (c) **liberty-delay screen** (sky130 tt, real cell delay, ps): second
  cost opinion; PDK fetched at job start via `ensure_pdk.py`
  (non-fatal if unavailable — recorded as `liberty_err`).

**Canaries (quarantine gates, fail-loud):**
- 4-bit flow canary (every shard): midori_sb0 == 3.0u exactly (proves the
  synth flow hasn't diverged; unchanged from the closed campaign).
- 8-bit emitter canary (every shard): pool's AES_SBOX == 10.7u exactly
  (calibrated locally 2026-10-12; proves the 8-bit emitter + flow).
- Gate non-vacuity (validated locally pre-submit): AES_SBOX + POW8_7 PASS;
  IDENTITY8 (DU=256, NL=0) REJECTED at gates, never synthesized.

## 5. S0 bar and escalation chassis (pre-registered)

- **S0 bar:** strictly < **18.6u** (current Frontier S speed point,
  t6_b59_47). If the frontier moves before escalation, the bar is the
  then-current speed point. XCHECK must be clean (C-vs-Python 10k).
- **Chassis:** 8-lane SPN, rounds ∈ {2, 3}, byte-permutation P-box +
  rotation schedule, pre-whitening + per-round key XOR. 2 rounds first
  (minimum plausibly quality-viable — 1 round is trivially
  distinguishable, so 2 is the principled floor, not an arbitrary pick);
  3 rounds as the pre-registered fallback if 2-round dies at S1/S2.
  The bundle generator (8-bit SPN bundler + P-box co-design) is built on
  the VM after harvest — it is VM-side work (the VM keeps in-context
  batteries), not part of this GHA campaign.

## 6. Pre-registered adjudication chain

| Stage | Pass rule | Kill rule |
|-------|-----------|-----------|
| Screen (GHA) | hard gates + synthesized; rank by crit | gate_fail / synth_fail → out |
| Top-5 → bundle | 5 cheapest gate-passers (or all, if fewer) | — |
| S0 (VM) | crit < 18.6u ∧ XCHECK clean | else **COST-CLOSED** (8-bit SPN line; pre-registered negative) |
| S1 | CAL_PASS (LIN/DIFF rej=0, marg PB/RD rej=0) | FLAG → KILLED |
| S2 | PASS (0 repeats, max\|z\| in bounds) | KILL → KILLED |
| S3 | PASS (PractRand 16M→1GB, no FAIL) | FAIL → KILLED |
| S4 | PASS (SmallCrush) | FAIL → KILLED |
| Q1 | sac_z5=0 ∧ bic_maxcorr ≤ 0.02 | else KILLED |
| Survivor | local PARETO adjudication (judgment stays local) | — |

GHA results are leads, never verdicts: every kill/claim is re-verified
against raw logs locally before touching PARETO.md or the ledger.

## 7. What success / failure looks like

- **Positive:** a gate-passing 8-bit box < ~8u → 2-round SPN bundle beats
  18.6u at S0 → staged battery. New frontier challenger line.
- **Negative (valid):** no box < ~8u → 8-bit SPN COST-CLOSED as a
  frontier line. The 8-bit (cost, quality) data still serves the hybrid
  track (8-bit box as hetero stage in non-SPN frames — co-designed,
  not blind-swapped).
- **Phase 2 (conditional):** if the cost thesis holds, affine-variant
  sweep (4096-variant scheme) of the winning class(es) — the 8-bit
  analog of the 4-bit variant sweep that found the 3.0u champion.
